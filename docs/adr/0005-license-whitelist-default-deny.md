# ADR 0005: ライセンスはホワイトリストで既定不採用。出典と取得日時を必ず保持する

- ステータス: 採用（2026-09-10）

## 背景
画像やデータの再利用は、明示的なライセンスがある場合に限る。曖昧なものは人手で判断せず自動的に不採用にする。

## 決定
- ホワイトリスト: CC BY（2.1 JP / 3.0 / 4.0）、CC0 1.0、政府標準利用規約（第 2.0 版）、CC BY 互換であると明記された自治体オープンデータ利用規約
- 対象外: BY-SA / BY-NC / BY-ND、規約が見つからないもの、「All Rights Reserved」のみのもの、判定不能なもの
- 判定 `LicenseVerdict{allowed, license_id, evidence_url, evidence_text, credit_text, checked_at, reason}` を保存し、採用時はページに元 URL・ライセンス名・取得日・クレジット文を表示する
- 検出はページ内の明示的な指標（creativecommons.org のライセンス URL、規約名の文字列）に限る。LLM に判定させない
- 物件写真は所有者提供の可能性が高いため、サイトのライセンスに関わらず原則除外する（サービス側の方針）
- 事実（価格・所在地など）の要約と出典リンクは著作物の利用ではないため、この判定の対象外。ただし本文の転載はしない（ADR 0004）

## 影響
- 全レコードが `Provenance{source_url, fetched_at, content_hash, extractor, license}` を持つ
- 画像の取得・保存（`assets/`）は今フェーズではインターフェースのみ。実装時もこの判定を通らない画像は保存しない
