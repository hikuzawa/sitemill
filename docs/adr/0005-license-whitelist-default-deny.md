# ADR 0005: ライセンスはホワイトリストで既定不採用。出典と取得日時を必ず保持する

- ステータス: 採用（2026-09-10）

## 背景
画像やデータの再利用は、明示的なライセンスがある場合に限る。曖昧なものは人手で判断せず自動的に不採用にする。

## 決定
- ホワイトリスト: CC BY（2.1 JP / 3.0 / 4.0）、CC0 1.0、政府標準利用規約（第 2.0 版）、CC BY 互換であると明記された自治体オープンデータ利用規約
- 対象外: BY-SA / BY-NC / BY-ND、規約が見つからないもの、「All Rights Reserved」のみのもの、判定不能なもの
- 判定 `LicenseVerdict{allowed, license_id, evidence_url, evidence_text, credit_text, checked_at, reason}` を保存し、採用時はページに元 URL・ライセンス名・取得日・クレジット文を表示する
- 検出はページ内の明示的な指標（creativecommons.org のライセンス URL、規約名の文字列）に限る。LLM に判定させない
- 物件写真は所有者提供の可能性が高いため、サイトのライセンスに関わらず原則除外する（サービス側の方針）
- 事実（価格・所在地など）の要約と出典リンクは著作物の利用ではないため、この判定の対象外。ただし本文の転載はしない（ADR 0004）

## 影響
- 全レコードが `Provenance{source_url, fetched_at, content_hash, extractor, license}` を持つ
- 画像の取得・保存（`assets/`）は今フェーズではインターフェースのみ。実装時もこの判定を通らない画像は保存しない

## 追記（2026-09-12）: 継承義務の無いライセンスを受け入れる

香川の 13 施設で実測したところ、Commons の候補 37 件のうち採用できたのは 5 件で、
却下の 31 件はライセンスが明確に読めた上でホワイトリスト外だった（ADR 0020 の実測）。
事業側の判断で、**継承（ShareAlike）の義務が生じないものはホワイトリストに入れる**ことにした。

追加したもの:
- CC BY 2.0 / 2.5（CC BY 4.0・3.0・2.1 JP はすでに対象）
- パブリックドメイン・マーク 1.0（`creativecommons.org/publicdomain/mark/1.0`）
- パブリックドメイン表示（`public domain` / `パブリックドメイン` / `PD-old`・`PD-Japan` 等）

**入れないもの**: CC BY-SA などの継承つきライセンス。受け入れた時点でサイトの該当部分に
取り消せない義務を負う。写真の枚数と釣り合わない（事業側の判断）。
`NO_SHARE_ALIKE == WHITELIST` をテストで固定し、継承つきを足したら落ちるようにした。

パブリックドメインの文字列一致は他より緩いので、**否定の書き方を拒否側に足した**
（「米国ではパブリックドメインだが他の国ではそうでない」という注記がある画像を拾わないため）。

この変更で、同じ 12 施設の採用は 5 枚 → 41 枚、写真が付いた施設は 23% → 83% になった
（カテゴリ名の確定による改善と合わせた数字。内訳は ADR 0020 と japan-open-today の
`data/runs/asset-probe-s4.json`）。
