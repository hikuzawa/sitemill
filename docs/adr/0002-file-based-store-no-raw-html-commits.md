# ADR 0002: 永続化は JSON/JSONL のファイル。生 HTML はコミットしない

- ステータス: 採用（2026-09-10）

## 背景
巡回状態（URL ごとのハッシュ・ETag・取得日時）と抽出レコードは実行環境をまたいで引き継ぐ必要がある。DB サーバーやマネージドサービスを増やすと人間側のアカウント作業が増える。

## 決定
- 巡回状態は `data/state/crawl.json`、抽出レコードは `data/records/<source_id>.jsonl`、実行レポートは `data/runs/*.json` としてサービス側リポジトリにコミットする（git-scraping 方式）
- 取得した生 HTML は `data/raw/` のローカルキャッシュにとどめ、コミットしない（.gitignore）。CI では actions/cache で持ち回る
- テスト用に必要な数ページだけ `tests/fixtures/html/` に保存する（出典 URL と取得日を付記）
- LLM 応答のキャッシュ `data/llm_cache/` も git 管理外
- JSON は key をソートして書き出し、差分が読めるようにする

## 理由
- git の差分がそのまま「何が変わったか」の記録になり、AI の自動改善ループが読める
- 生 HTML は第三者の著作物であり、private リポジトリでも複製を増やさない。必要なら再巡回すればよい

## 影響
- レコードは要約・数値・短い引用・出典 URL のみを持ち、本文は保持しない
- 履歴が肥大化したら data をブランチ分割する（将来の ADR）
