# ADR 0008: 視覚要素は埋め込み・SVG 図解・ライセンス通過画像の三系統。生成画像は説明図に限る

- ステータス: 採用（2026-09-10）

## 背景
実在の物件や場所を AI 画像生成で描くことは禁止。視覚要素は出典とライセンスを説明できるものに限る。

## 決定
- `embeds/`: Google Maps Embed API（place / streetview）と公式 SNS（YouTube / Instagram / X）の埋め込みを `Embed{kind, provider, src_url, link_url, attribution, license_note, fetched_at}` で表す。埋め込み機能経由のみ、転載はしない。地図はキーが無いときは外部リンクにフォールバックする。SNS は今フェーズではインターフェースのみ
- `charts/`: 依存なしの SVG 生成（棒グラフ・ヒストグラム・手続きフロー図）。`<title>`/`<desc>` を持ち、色は CSS 変数で指定する。出力には自動生成の図解であることを示す属性を付ける
- `assets/`: ライセンス判定（ADR 0005）を通過した画像だけを取得・保存し、クレジットを保持する。今フェーズはインターフェースのみ
- AI 画像生成は手続きの説明図やピクトグラムなど「イメージ図」に限り、生成物であることを明記するヘルパー経由でしか置けない

## 影響
- 各サービスは優先順位（地図 → 図解 → 公式 SNS → ライセンス通過写真）を自分の ADR で定める
- Street View は緯度経度が必要なため、ジオコーディングを導入するまでは place モードだけを使う
