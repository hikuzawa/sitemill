# ADR 0010: 抽出精度を fixture で計測し、自動改善ループの入力にする

- ステータス: 採用（2026-09-10）

## 背景
運用・改善を AI が自動で回すには、プロンプトやパーサの変更が抽出にどう効いたかを数値で確かめる必要がある。

## 決定
- `sitemill eval` は `tests/fixtures/eval/<case>/` の保存済み HTML と、期待レコード（`expected.json`）、保存済み LLM 応答（`llm_response.json`）を使い、外部アクセスなしで抽出パイプラインを通す
- 集計するもの: 項目ごとの抽出率（value が得られた割合）、null 理由の内訳（not_found / unparsed / quote_not_in_source）、期待値との一致率、要約の転載判定の件数
- 結果は JSON と表で出し、`data/runs/` の実行レポートにも本番の項目別状態を同じ形で載せる
- fixture の期待値は人または AI が原文を見て作り、根拠の引用を併記する

## 影響
- プロンプト版を上げるときは eval の前後を比べて記録する
- 本番の実行レポートと eval の指標が同じ形なので、劣化検知に使える
